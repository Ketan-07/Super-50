# 🔹 DSA Problems

### 41. Linear Search

Search for a target element by checking each element sequentially.

**Time Complexity:** `O(n)`

### 42. Binary Search

Search for an element in a sorted list by repeatedly dividing the search space.

**Time Complexity:** `O(log n)`

### 43. Bubble Sort

Sort elements by repeatedly comparing and swapping adjacent elements.

**Time Complexity:** `O(n²)`

### 44. Stack Implementation

Implement a stack using a Python list following the **LIFO** principle.

**Operations:** Push, Pop, Peek

### 45. Queue Implementation

Implement a queue using `deque` following the **FIFO** principle.

**Operations:** Enqueue, Dequeue

### 46. Balanced Brackets

Use a stack to determine whether opening and closing brackets are correctly matched.

**Concept:** Stack

### 47. Missing Number Using Formula

Find a missing number using the mathematical formula:

```text
n × (n + 1) / 2
```

**Time Complexity:** `O(n)`

### 48. Maximum Subarray Sum

Find the maximum possible sum of a contiguous subarray using **Kadane's Algorithm**.

**Time Complexity:** `O(n)`

### 49. Majority Element

Find the element that occurs more than `n/2` times using the **Boyer-Moore Voting Algorithm**.

**Time Complexity:** `O(n)`

### 50. Two Sum

Find two elements whose sum equals a given target using a dictionary/hash map.

**Time Complexity:** `O(n)`
