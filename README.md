# 🔹 DSA Problems

## 41. Linear Search

Search for a target element by checking each element sequentially.

**Time Complexity:** `O(n)`
**Space Complexity:** `O(1)`

---

## 42. Binary Search

Search for an element in a **sorted list** by repeatedly dividing the search space into two halves.

**Time Complexity:** `O(log n)`
**Space Complexity:** `O(1)`

---

## 43. Bubble Sort

Sort elements by repeatedly comparing and swapping adjacent elements when they are in the wrong order.

**Time Complexity:** `O(n²)`
**Space Complexity:** `O(1)`

---

## 46. Reverse a Linked List

Reverse the direction of the links in a singly linked list.

### Example

```text
Original:
10 → 20 → 30 → 40 → None

Reversed:
40 → 30 → 20 → 10 → None
```

The solution uses `prev`, `current`, and `next` pointers to reverse the links.

**Time Complexity:** `O(n)`
**Space Complexity:** `O(1)`

---

## 47. Find Middle of Linked List

Find the middle node of a singly linked list without calculating its length.

The solution uses the **slow and fast pointer** technique. The slow pointer moves one step while the fast pointer moves two steps.

### Example

```text
10 → 20 → 30 → 40 → 50

Middle:
30
```

**Time Complexity:** `O(n)`
**Space Complexity:** `O(1)`

---

## 48. Maximum Subarray Sum

Find the maximum possible sum of a contiguous subarray using **Kadane's Algorithm**.

### Example

```text
Input:
[-2, 1, -3, 4, -1, 2, 1, -5, 4]

Maximum Sum:
6

Subarray:
[4, -1, 2, 1]
```

**Time Complexity:** `O(n)`
**Space Complexity:** `O(1)`

---

## 49. Majority Element

Find the element that occurs more than `n/2` times in an array.

The **Boyer-Moore Voting Algorithm** uses a candidate and counter to find the majority element efficiently.

**Time Complexity:** `O(n)`
**Space Complexity:** `O(1)`

---

## 50. Merge Two Sorted Arrays

Merge two already sorted arrays into a single sorted array.

### Example

```text
Array 1:
[1, 3, 5, 7]

Array 2:
[2, 4, 6, 8]

Result:
[1, 2, 3, 4, 5, 6, 7, 8]
```

The solution uses **two pointers** to compare elements from both arrays and merge them in sorted order.

**Time Complexity:** `O(n + m)`
**Space Complexity:** `O(n + m)`
